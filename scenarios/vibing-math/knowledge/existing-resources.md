# Existing Resources

## Purpose

This file is a high-level resource map. It is not yet a structured literature index.

Agents should use it to identify candidate areas for literature-index entries, taxonomy entries, and proof-route comparisons. Specific bibliographic details should be added through dedicated literature-index tasks, not invented here.

## Classical Directions

Goldbach-related work connects to long-standing questions in additive number theory, especially the representation of integers as sums of primes.

Agents should distinguish:

- binary Goldbach-type statements;
- ternary or weak Goldbach-type statements;
- conditional results;
- partial results;
- computational verification.

## Analytic Number Theory

Analytic number theory provides major tools for studying primes and additive representations.

Relevant themes include:

- prime distribution;
- exponential sums;
- circle-method-style decompositions;
- major and minor arc analysis;
- estimates under hypotheses;
- asymptotic and average statements.

Agents should avoid claiming that an analytic method proves the full conjecture unless the exact result is sourced and reviewed.

## Sieve Methods

Sieve methods are relevant because they study sets of integers with restricted prime factors.

Useful topics include:

- upper and lower bound sieves;
- almost-prime results;
- parity limitations;
- Chen-type directions;
- relationship between almost-prime representations and prime-prime representations.

A good task would map what sieve methods can prove and where the known barriers arise.

## Computational Verification

Computational verification is important as evidence and as a source of boundary-case information.

Agents should record:

- verified range;
- algorithm;
- implementation basis;
- reproducibility;
- relation to theoretical methods;
- what remains unproved.

## Related Partial Results

Partial-result categories should be mapped carefully.

Potential categories:

- representations involving three primes;
- one prime plus one almost-prime;
- results for sufficiently large integers under conditions;
- density or average-case versions;
- conditional results based on stronger hypotheses.

## Survey Material

Survey material is useful for orientation, but should be converted into structured literature-index entries.

A survey summary should not become a substitute for source-specific entries.

## How Agents Should Use This File

Agents should use this resource map to propose narrow tasks such as:

- create a literature entry for a specific source;
- create a taxonomy entry for a method family;
- compare two proof routes;
- identify a known obstruction;
- create a failed-path entry for a tempting but insufficient route.

Agents should not cite this file as proof of a mathematical claim. It is a navigation aid, not an authority.
